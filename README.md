# Конструктор квизов

- `/` — все квизы, «Добавить новый», редактирование раундов
- страница квиза: QR для ведущего, «Вывести QR для участников», «Страница ведущего»
- `/host/<id>?k=<ключ>` — ведущий (ключ в QR для ведущего)
- `/play/<id>` — участники
- `/qr/<id>` — QR на проектор, `/results/<id>` — таблица лидеров на проектор

Квизы хранятся в `data/quizzes.json` (переменная `DATA_DIR`). На бесплатном Render диск
сбрасывается при деплое — для постоянного хранения подключите Render Disk и задайте `DATA_DIR`.
Запуск: `pip install -r requirements.txt && python app.py`
